# Portafolio Backend

Backend Express preparado para desplegarse en Vercel como Serverless Function.

## Scripts

```bash
npm install
npm run build
npm start
```

## Variables de entorno

Configura estas variables en Vercel antes de desplegar:

```bash
EMAIL_USER=
EMAIL_PASS=
```

## Endpoints

- `GET /`
- `GET /api/health`
- `POST /api/contact`
